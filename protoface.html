How to use this

An animation is a list of frames. Each frame is a picture of the face plus how long it stays up.

  • Draw by clicking and dragging on the dots. Hold to keep painting.
  • Mirror is on by default — draw one side, the other side follows.
  • + Frame adds a blank frame; Duplicate copies the current one, which is usually what you want when animating.
  • Onion shows the previous frame faintly, so you can see how far things moved.
  • Drag frames along the strip at the bottom to reorder them.
  • Changing anything stops playback — so a duration you're typing can't smear across frames while the playhead moves.
  • Undo goes back 80 steps. A whole drag is one step, and so is a whole number typed into the duration box.
  • Export writes a .json the ProtoESP firmware reads directly.

Getting it onto the helmet

Either drop the file into ProtoESP-Controller/data/anims/ and upload the filesystem, or connect to the helmet's WiFi (ProtoWiFi) and upload it from the phone page.

Keys

⌘Z undo   ⇧⌘Z redo   Space play/pause   ← → prev/next frame   D duplicate frame   E eraser   M mirror   O onion   Backspace delete frame

With the cursor over a pixel: R toggles that row right across its screen, C toggles that column. With a panel selected: [ ] rotate, ⌘C ⌘V copy and paste it.
